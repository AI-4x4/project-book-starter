# Стартовый репозиторий проектной Книги — v0.1.0 preview

Это экспериментальный стартовый пакет. [English version](README.md). Требуется Python 3.10 или новее; внешних зависимостей нет. [Команды запуска](docs/QUICKSTART.md), [что реализовано](docs/STATUS.md), [описание выпуска](RELEASE-NOTES.md). Здесь два маршрута работы с разрешённым исходным материалом:

- **Обычный:** извлечь из диалогов относящиеся к проекту утверждения с указанием источника → сверить противоречия и пробелы с владельцем → составить и утвердить ТЗ, не потеряв цель → реализовать и проверить результат.
- **Для сложного/изменяющегося замысла:** после извлечения отдельно записать авторский замысел без технических решений → развить проектную Книгу с причинами решений, неизвестным, версиями и порядком изменений → считать ТЗ, архитектуру, код и тесты производными по мере необходимости. Непостроенное будущее не выдавать за существующее.

Начало: скопируйте `templates/common/` плюс **одну** из `templates/standard/` или `templates/complex/` в *отдельный проект*. Сырые переписки и частные файлы сюда не копировать по умолчанию. `docs/PROCESS.md` описывает шаги, `docs/DECISIONS-AND-CHANGES.md` — границы решений, `farshmaster/` — ограниченные два прохода «сырой смешанный текст → фрагменты и кандидаты категорий/области → кандидат картины» с сохранением источников и неизвестного (не канонизация); `monitoring/` — базовая read-only проверка наличия файлов и свежести заявленного наблюдения; не проверка полезного эффекта. `docs/EXTENSIONS.md` — запас на дальнейшие исследовательские/контрольные возможности без их ложной «установки». `RELEASE-REVIEW.md` — контроль перед любым публичным выпуском. Структурная проверка: `python3 checks/check_starter.py`; она не доказывает смысл, полномочия и пользовательский эффект.

Источником решений каждого проекта остаётся его владелец; этот шаблон не даёт права менять чью-либо проектную Книгу. Новые компоненты добавляются по проверенной потребности, а не из-за наличия места в каталоге.
