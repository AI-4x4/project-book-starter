# Фаршмастер: первый ограниченный срез

**Language / Язык:** [English](README.md) · [Русский](README.ru.md) · [Home / Главная](../README.ru.md)

**Два прохода:** (1) берёт разрешённые по происхождению фрагменты JSONL и раскладывает по *указанной* категории либо выдаёт узкую эвристическую метку-кандидат для распознаваемых начальных формулировок; неоднозначное оставляет `unknown`. (2) строит обозримого кандидата протоидеи из ссылок на исходные фрагменты и сохраняет противоречия, допущения и пробелы. Не пишет в Книгу и не утверждает решение владельца.

12 названий из раннего примера обсуждения, не утверждённая окончательная таксономия: `intention`, `desired_result`, `problem`, `example`, `fact`, `assumption`, `preference`, `constraint`, `decision`, `question`, `contradiction`, `unknown`. Метка `decision` обозначает *заявленный* тип фрагмента, не доказывает полномочие или принятие. «Третий слой» модели желаемого результата остаётся предложением, не реализован.

Для неразмеченного потока: `python3 -m farshmaster.core --raw --source-id synthetic --source-role author --project-term "Проект Соседи" examples/fictional-app/mixed-raw.txt`. Неотмеченное имя проекта **не доказывает**, что фрагмент посторонний; оно остаётся в `needs_scope_review`. Имя проекта в строке — лишь кандидат релевантности, не подтверждение. Смешанный поток сохраняется построчно с указанием источника, позиции и хэша; семантическое выделение нескольких мыслей в одной строке ещё не выполнено. При смешении личного и проектного сохраняйте вывод только в приватном месте: stdout содержит исходные тексты.

Формат каждой строки JSONL: `{"id":"A","source":"source ID/time","text":"...","category":"intention","scope":"project","contradicts":["B"]}`. Обязательны `id`, `source`, `text`; необязательны `category`, `scope`, `contradicts`; без `scope` фрагмент остаётся не включённым в проектную протоидею до разбора. Не помещайте частные чаты в публичный репозиторий. Команда из корня: `python3 -m farshmaster.core /path/to/permitted-fragments.jsonl` — результат только в stdout; перенаправляйте его только в защищённый проектный каталог. Тесты: `python3 -m unittest discover -s farshmaster -p 'test_*.py'`.

**Граница:** это детерминированная узкая классификация и проверяемая сборка, а не агент, который понимает произвольный грязный текст. Семантическую классификацию произвольной смеси, качество синтеза, полноту происхождения, утверждение замысла автором и реальный пользовательский эффект этот код не проверяет. Для такого перехода нужны отдельный адаптер/испытания и решение владельца.
