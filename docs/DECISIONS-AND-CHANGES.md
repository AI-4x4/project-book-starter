# Decision and amendment protocol (owner must adapt)

- Each significant statement has a scope, origin, version and type: reported fact, hypothesis, owner decision, observed result or unknown.
- Proposals list the prior basis, reason, dependent decisions/artifacts, alternatives and test. The owner confirms any change to author intent under the project's agreed process.
- Record former decisions and why they were replaced. A code change is not automatically a goal amendment.
- Reading, editing, executing and publishing are distinct permissions. Repository access grants none by itself.
- On unknown authority, pause the dependent action and retain safe analysis and reporting.
